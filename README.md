# Pro Нейронки — сайт-визитка

Одностраничный сайт эксперта по нейросетям: курсы, отзывы, контакты.

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4
Сторонних UI-библиотек, иконочных паков и рантайм-API нет — только эти три пакета и React.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер |
| `npm run build` | Продакшен-сборка |
| `npm run start` | Запуск собранного приложения |
| `npm run lint` | ESLint |
| `npm run typecheck` | Проверка типов без сборки |

## Деплой на Vercel

Vercel определяет Next.js сам — никаких `vercel.json` и настроек сборки не требуется.

1. **Vercel → Add New → Project → Import** репозиторий `Website_teregelena`.
2. Framework Preset подставится как **Next.js**. Build Command, Output Directory и Install Command не трогать.
3. **Settings → Environment Variables** — добавить, когда появится свой домен:

   | Переменная | Значение | Окружения |
   | --- | --- | --- |
   | `NEXT_PUBLIC_SITE_URL` | `https://ваш-домен.ru` (без слэша на конце) | Production |

   Без неё сайт возьмёт адрес из `VERCEL_PROJECT_PRODUCTION_URL`, который Vercel подставляет сам, и будет ссылаться на `*.vercel.app`. Это рабочий вариант, но после подключения своего домена переменную нужно задать и передеплоить — иначе canonical и Open Graph останутся на старом адресе.

4. **Deploy.** Прод собирается из ветки по умолчанию (`main`), поэтому рабочую ветку нужно сначала влить в неё. До слияния каждый push создаёт Preview-деплой со своей ссылкой — на нём удобно всё проверить.
5. Свой домен: **Settings → Domains → Add**, дальше Vercel покажет, какие DNS-записи прописать у регистратора.

После первого деплоя стоит проверить:

- `/robots.txt` и `/sitemap.xml` открываются и содержат правильный домен;
- превью ссылки в Telegram (просто отправьте её себе) — должна подтянуться обложка;
- в [Search Console](https://search.google.com/search-console) и Яндекс.Вебмастере добавить сайт и отправить `sitemap.xml`.

## Что заполнить перед публикацией

Весь текст и данные вынесены в `src/content/` — верстку для этого трогать не нужно.

1. **`src/content/site.ts`** — название, тексты, ссылки на мессенджеры.
   Ссылка на MAX пока заглушка (`https://max.ru/username`).
2. **`src/content/about.ts`** — текст «Обо мне» и цифры в блоке статистики.
3. **Аватары в отзывах** — сейчас нейтральные силуэты. Заменять на стоковые лица нельзя: это выдавало бы чужих людей за авторов отзывов. Либо реальные фото, либо оставить как есть.
4. **`design/og-image.svg`** — обложка ссылки в соцсетях.
   После правки пересоберите растр: `node design/build-og.mjs` (нужен `playwright` и Chromium, в зависимостях проекта его нет).

### Про фотографии

Снимки на первом экране и в блоке «Обо мне» сняты на чёрном фоне: это вырезанные силуэты, сохранённые в JPEG, а он не поддерживает прозрачность. Убрать фон автоматически нельзя — тёмная одежда почти не отличается от фона по яркости, и вырез по порогу съел бы платье. Поэтому чёрный обыгран намеренно: снимки поданы тёмными панелями со скруглением и свечением.

Если появятся PNG с настоящей прозрачностью, в `Hero.tsx` и `About.tsx` достаточно вернуть `object-contain` и убрать тёмную подложку.

## Структура

```
src/
├── app/            маршруты, layout, sitemap.ts, robots.ts, иконки
├── components/
│   ├── layout/     Header, MobileMenu, Footer, Logo
│   ├── sections/   секции главной страницы
│   └── ui/         переиспользуемые примитивы и иконки
├── content/        весь текст и данные сайта
├── hooks/          useInView, useLockBodyScroll
├── lib/            cn(), метаданные и JSON-LD
└── types/          доменные типы
```

**Клиентских компонентов ровно четыре** — `Header`, `MobileMenu`, `Reveal` и хуки к ним.
Всё остальное рендерится на сервере, поэтому в браузер уезжает минимум JavaScript.
Аккордеон FAQ сделан на нативных `<details>` и работает вообще без скриптов.

## Секции главной

Hero → Что вы получите → Курсы → Обо мне → Как проходит обучение → Отзывы → Призыв → FAQ → Контакты

Секции «Обо мне», «Как проходит обучение», FAQ и футер добавлены сверх исходного макета:
на «Обо мне» вёл пункт меню, но самой секции не было, а остальное закрывает типовые вопросы посетителя.

## SEO

- Метаданные, Open Graph и Twitter Card — `src/lib/seo.ts`
- `sitemap.xml` и `robots.txt` — `src/app/sitemap.ts` и `src/app/robots.ts`
- Разметка schema.org (`Person`, `WebSite`, `Course`, `FAQPage`) собирается из тех же данных, что и видимый текст
- Все страницы полностью статические (SSG)

## Добавить страницы курсов

Заготовка под это уже есть: у каждого курса в `src/content/courses.ts` заполнен `slug`.
Понадобится создать `src/app/courses/[slug]/page.tsx` с `generateStaticParams` и `generateMetadata`,
поменять `href` в `src/components/sections/Courses.tsx` и добавить страницы в `sitemap.ts`.
